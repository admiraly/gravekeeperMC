# gravestone

Created in [T3 Code](https://t3.codes).

A Paper 26.3 plugin. When you die, your items and XP are stored in a gravestone
at your death spot. Right-click it to get everything back. Nothing is dropped as
an item entity, so nothing despawns.

Build: `./gradlew build` (Java 25) -> `build/libs/GraveKeeper-1.0.0.jar`, drop into `plugins/`.
